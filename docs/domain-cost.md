## 2. 「1年目が安いところで取って、更新前に他社へ移す」は現実的か

### 2-1. 60日ルールは実在する（各社の公式記述で確認済み）

| 社名 | 公式の記述（逐語） | 出典 |
|---|---|---|
| Cloudflare Registrar | "Your domain was registered at least 60 days ago and has not been transferred in the last 60 days (ICANN requirement)." / "You have not changed your registrant name, organization, or email address in the last 60 days. Under ICANN rules, changes to these fields trigger a 60-day transfer lock." | [transfer-domain-to-cloudflare](https://developers.cloudflare.com/registrar/get-started/transfer-domain-to-cloudflare/) |
| Value Domain | 「新規取得、レジストラ移管を行ってから、60日間は移管処理を行うことができません。」（さらに残存期限14日以上が必要） | [domain/transfer/](https://www.value-domain.com/domain/transfer/) |
| お名前.com | 移管不受理原因として「ドメイン登録、前回の移管申請から 60日経過していない」。加えて残存期限は .jp 31日以上／.jp 以外 **15日以上**、残存9年以上は移管不可 | [help/8577](https://help.onamae.com/answer/8577) |
| Xserverドメイン | 「移管元でレジストラロックがかかっている（取得より60日経過していない）」 | [faq_domain_transfer.php](https://www.xdomain.ne.jp/support/faq/faq_domain_transfer.php) |
| ムームードメイン | 移管できない理由として「取得から60日以内のドメイン」。残存14日以内／期限切れも不可、残存9年超も不可 | [support/360046369373](https://support.muumuu-domain.com/hc/ja/articles/360046369373) |

**結論: 60日ルールは ICANN 由来で全社共通。** 1年契約なら 60日はすぐ過ぎるので、**「60日縛りが原因で移管できない」ことは起きない。**

### 2-2. それでも「毎年移管して渡り歩く」はコスト的に得にならない

移管は**タダではなく、1年分の更新料と同額を払って1年延長される**のが標準。

- Value Domain: 「移管作業にはそれぞれのドメインの1年分の更新料がかかります。移管完了時点で、自動的に1年分の延長がなされます。」（[出典](https://www.value-domain.com/domain/transfer/)）
- Xserverドメイン: 「移管元のWhois情報上の利用期限から1年延長された日付が新しい利用期限になります」。移管料 **1,721円**（[出典](https://www.xdomain.ne.jp/domain/price.php)）
- Cloudflare: "For most generic TLDs (such as `.com`, `.net`, and `.org`), the transfer price includes a one-year registration extension from your current expiration date."（[出典](https://developers.cloudflare.com/registrar/get-started/transfer-domain-to-cloudflare/)）

つまり**「移管料 ≒ 移管先の更新料」**なので、渡り歩いても払う額は「移管先の更新料」に収束する。1年目0円の会社を毎年転々としても、**0円が再適用されることはない**（0円は「はじめての方」「1ドメイン目」限定のキャンペーン）。

さらに実務上の摩擦:

1. **ムームードメインは WHOIS 代理公開が有効だと外部へ移管できない** — 移管前に代理公開を解除する必要があり、その間 WHOIS に自分の情報が露出する（[出典](https://support.muumuu-domain.com/hc/ja/articles/360046369373)）。
2. **登録者名義・組織名・メールアドレスを変えると 60日の移管ロックがかかる**（ICANN ルール。Cloudflare が明記）。
3. **残存期限が短いと移管不可**（お名前.com は15日以上、Value Domain / ムームーは14日以上）。「更新直前に移管」はギリギリだと弾かれる。
4. 移管は承認メールの往復と数日の待ちが必要（ムームーは承認メール4日以内）。ネームサーバ設定の引き継ぎ漏れでサイトが落ちるリスクもある。

### 2-3. 判定

> **「1年目だけ安いところで取って毎年移管し続ける」運用は、コスト的にほぼ無意味なので非推奨。**
> ただし **「1年目を0円の会社で取り、2年目の更新が来る前に1回だけ、更新料の安い（または原価の）会社へ移管する」** のは、60日ルールもクリアでき、合理的。移管料として1年分を払うので、実質は「1年目0円＋2年目以降は移管先の更新料」になる。
> 逆に「ずっと同じ場所」で行くなら、**1年目の安さより2年目以降の更新料だけを見て選ぶ**のが正解。

## 3. 推薦: `mirumado.com` をどこで取るか

### 前提条件（Cloudflare Pages で公開）

Cloudflare Pages にカスタムドメインを当てるので、**ネームサーバを Cloudflare に向けられること**が必須。

- **Cloudflare Registrar は必須でそうなる**: "All domains acquired via Cloudflare Registrar use Cloudflare nameservers... You will not be able to change to another DNS provider's nameservers while using Cloudflare Registrar."（[出典](https://developers.cloudflare.com/registrar/get-started/register-domain/)）／ "Cloudflare Registrar requires your domain to use Cloudflare for authoritative DNS (full setup)."（[出典](https://developers.cloudflare.com/registrar/get-started/transfer-domain-to-cloudflare/)）
- 他4社はいずれも管理画面でネームサーバを任意の値に変更できる一般的なレジストラなので、Cloudflare の NS を指定すれば問題ない（※各社の「ネームサーバ変更可否」の逐語確認はこの調査では未実施 = **取得できず**）。

### 推薦（総額で安い順）

**第1候補: お名前.com で 0円取得 → 60日経過後・1年目の更新が来る前に Cloudflare Registrar へ移管**

- 1年目: **0円**（`.com` 0円キャンペーン、1ドメイン目）＋ Whois 情報公開代行を**同時申込で 0円**
- 2年目以降: Cloudflare の原価更新（**金額は公開されていないため実額は取得できず**。ダッシュボードで要確認）
- Cloudflare は WHOIS 秘匿が無料、自動更新がデフォルトON、更新はレジストリの list price のみで値上げ操作がない
- Cloudflare へ移すと NS が強制的に Cloudflare になるので、**Pages 運用と完全に一致**（むしろ都合が良い）
- 注意: 移管には 1年分の移管料がかかる。お名前.com 側の「サービス維持調整費」が 0円取得時にも乗るかは公式に明記されておらず **取得できず**

**第2候補（移管の手間を避けたい／1社で完結させたい場合）: Xserverドメイン**

- 1年目 **0円**、2年目以降 **1,721円/年（税込）**、Whois 代理公開 **無料**、追加費用なしを明記
- 5年総額 **6,884円**。表示が完全税込で、サービス維持調整費のような上乗せの記載もない
- お名前.com の見かけの更新料（1,408円）より高いが、**お名前.com はサービス維持調整費が別途乗る**ため、実請求ベースでは差が縮む可能性がある（調整費の率は公式ページを取得できず **取得できず**）

**第3候補: Value Domain（GMOレジストラ）**

- 新規 790円 / 更新 1,986円、WHOIS 公開代行が**明文で無料**、移管条件も公式に明記されていて透明性が高い
- ただし更新料は上位2社より高い

**避けたい選択**

- **eNom / KeySystems バックエンドの Value Domain**（2,231〜2,643円/年）と**スタードメイン**（更新2,047円）は、更新料が明確に高い。
- ムームードメイン（更新1,728円）は Xserver とほぼ同額だが、**WHOIS 代理公開の料金が公式に確認できず**、かつ**代理公開が有効だと外部移管できない**制約があるため、あとで Cloudflare に逃がしたい場合に一手間増える。

### 最終推奨

> **`mirumado.com` は Cloudflare Registrar が長期的に最安の可能性が高いが、公式に金額が一切公開されていないため確定できない。**
> 実務的には次の2択:
> 1. **長期最安狙い**: お名前.com で 0円取得（Whois 代行も同時申込で0円） → 60日後〜1年目の更新前に **Cloudflare Registrar へ移管**。移管後は NS が Cloudflare 固定になり Pages と整合。**ただし Cloudflare の `.com` 実額を先にダッシュボードで確認すること。**
> 2. **手間最小・金額確定**: **Xserverドメイン**で 1年目0円 → 以後 **1,721円/年（税込）**、Whois 代理公開無料。5年総額 6,884円で完全に見積もりが確定する。
