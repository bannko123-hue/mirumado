## ③ タグの入れ方

**手順の原本は `docs/ad-placement.md` §3-2 です。この文書では繰り返しません。** 迷ったら §3-2 を開いてください。要点だけ再掲します。

1. **足すのは `ad_slots` の該当項目に `html:` の1行だけ。** 本文は触らない（`::ad{id=...}` は既にある）。
2. **タグは ASP の管理画面からコピーしたものを、一字も変えずに貼る。** 改行が入っていたら**改行だけを消して1行にする**。それ以外は触らない。
   - 理由: **A8.net は「広告素材の改変」を禁止事項として明記している**（出典: https://www.a8.net/compliance/prohibited-matter.php ・2026-09-07 確認）。**afb のタグについても同じ扱いにする**（afb 側の規約はログインが必要で未確認のため、厳しいほうに合わせる）。
   - **`href` だけを抜き出して Markdown のリンク記法にしない。** `html:` はエスケープされないので、抜き出す必要がそもそもありません。
3. **値はシングルクォート `'` で囲む。** HTML タグには `"` が大量に入るため。
4. **テキストリンクを選ぶ。** このサイトは外部画像を一切読み込まない設計なのでバナーは使いません。
5. 貼ったら `node build.mjs --check` を実行し、**「広告枠 57 箇所（うちタグ挿入済み N 箇所）」の N が増えているか**を見る。増えていなければ貼れていません。
6. `node serve.mjs` で開き、**「広告」の小さいラベルが枠の上に出ていること**を目で確認する。出ていなければ公開しない。
7. **自分のリンクを踏まない**（自己クリックは A8 の禁止事項）。
