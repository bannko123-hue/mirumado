この記事の料金・条件は 2026-10-03 時点でスカパー！の公式ページを確認したものです。本記事にはアフィリエイト広告を含みます。

スカパー！の「基本プラン」は、月額視聴料3,960円（税込）で50チャンネルが見放題になるプランです::source{1}。映画やドラマ、音楽、アニメと並んで**スポーツのジャンルが4チャンネル**入っていて、プロ野球の中継で名前を聞くチャンネルも含まれます::source{1}。

ただし、**基本プランは「プロ野球専用の商品」ではありません。** 野球を中心に見たい人向けには別に「プロ野球セット」があり、中身が一部重なっています::source{1}::source{9}。この記事では、基本プランでスポーツがどこまで見られるのか、プロ野球セットとどう違うのか、そして**2026年10月31日申込み分まで実施中の「視聴料最大3ヶ月半額」キャンペーン**で実際の支払いがいくらになるのかを、公式ページで確認できた範囲だけで整理します。確認できなかった点は、そのまま「確認できなかった」と書いています。

## 結論：初めての加入なら、10月中の申込みが一番安い

| 判断の軸 | 確認できたこと |
| --- | --- |
| 通常の月額 | 基本プラン視聴料3,960円＋基本料429円＝**4,389円**（いずれも税込・記事側の足し算）::source{1}::source{3} |
| キャンペーン中 | 加入月は0円。翌月から最大3ヶ月は視聴料1,980円＋基本料429円＝**2,409円**（税込・記事側の足し算）::source{2} |
| 対象になる人 | **初めてスカパー！に加入し、加入と同じ月に基本プランを契約した人**。2026年8月1日〜10月31日の申込み分::source{2} |
| スポーツ | スカイA／GAORA SPORTS／日テレジータス／スポーツライブ＋の4チャンネル::source{1} |
| 台数 | 条件を満たせばテレビ・レコーダー3台まで追加料金なし::source{5} |
| 録画 | できる（一部の番組は不可）::source{1}::source{2} |

**向いているのは、野球「だけ」ではなく、映画やドラマ、音楽なども含めて家族でテレビを楽しみたい人**です。50チャンネルの中にスポーツ専門チャンネルが4つ入り、しかも条件付きで3台まで同じ料金で見られるので、1契約で家族全員の見たいものをまかないやすい構成です::source{1}::source{5}。

逆に、**J SPORTSで放送される試合まで追いたい人には基本プランだけでは足りません**（後述）。

## 「最大3ヶ月半額」キャンペーンの中身

スカパー！は2026年10月31日までの申込み分を対象に、基本プランの視聴料を割り引くキャンペーンを行っています::source{2}。仕組みを順番に書くと次のとおりです。

1. **加入した月は、基本料も視聴料もかからない**（0円）::source{2}
2. **加入した翌月から最大3ヶ月間、基本プランの視聴料が1,980円（税込）になる。** 通常3,960円のちょうど半額です::source{1}::source{2}
3. **割引の期間が終わると、視聴料は通常の3,960円（税込）に戻る**::source{2}

注意したいのは、**割引されるのは「視聴料」だけで、基本料429円（税込）は別に毎月かかる**ことです::source{2}。キャンペーン中の実際の請求は、1,980円に429円を足した**月2,409円**になります（記事側の足し算）。割引額は視聴料1,980円×最大3ヶ月で、**最大5,940円**です（記事側の計算）。

対象になるのは、**初めてスカパー！に加入する人が、加入と同じ月に基本プランを契約した場合**に限られます::source{2}。キャンペーン期間（2026年8月1日〜10月31日の申込み受付分）の外で加入した場合や、**以前に解約したときと同じB-CASカード・ACAS番号で入り直す場合**は対象外です::source{2}。以前スカパー！を契約していたテレビやレコーダーで入り直す場合は、カード番号が当時と同じかどうかを先に確認してください。

### 10月に申し込んだ場合の支払いの例

公式の条件をもとに、2026年10月中に加入して基本プランを契約した場合を当てはめると、次のようになります（記事側の計算）::source{2}::source{3}。

| 月 | 請求額（税込） |
| --- | --- |
| 2026年10月（加入月） | 0円 |
| 2026年11月〜2027年1月 | 各月2,409円（視聴料1,980円＋基本料429円） |
| 2027年2月以降 | 4,389円（視聴料3,960円＋基本料429円） |

公式の表記は「最大3ヶ月間」なので、途中で解約すれば割引を受ける月数もそこまでになります::source{2}。

## 解約のルールは先に知っておく

スカパー！は、月額の配信サービスとは解約の考え方が違います。公式FAQで確認できたのは次の3点です::source{4}。

- **加入した月のうちは解約の手続きができない。** 手続きは翌月以降になる
- **解約日は、手続きが完了した月の末日。** 日にちを指定することはできない
- **解約した月の分まで料金がかかる**

つまり、キャンペーンで入った場合も**最低でも加入翌月の2,409円は必ずかかります**（記事側の足し算）::source{2}::source{4}。また、前月に解約したチャンネルを同じカード番号で契約し直すと、その月の分から視聴料がかかります::source{3}。「とりあえず入って、合わなければすぐやめる」という使い方には向かないので、申し込む前に見たいチャンネルがあるかを確かめてから決めてください。

## 基本プランで見られるスポーツと、プロ野球セットとの違い

基本プランのスポーツジャンルに入っているのは、**CS250 スカイA、CS254 GAORA SPORTS、CS257 日テレジータス、CS800 スポーツライブ＋**の4チャンネルです::source{1}。

一方、月額視聴料4,054円（税込）の「プロ野球セット」は12チャンネル構成で、スポーツは**この4つに J SPORTS 1・2・3（BS242〜244）を加えた7チャンネル**です::source{9}。両方の公式ページを突き合わせると、プロ野球セットの12チャンネルのうち **J SPORTS 1〜3 を除く9チャンネル（スポーツ4・総合エンタメ4・ニュース1）は基本プランにも入っています**（記事側の整理）::source{1}::source{9}。

| 比べる点 | 基本プラン | プロ野球セット |
| --- | --- | --- |
| 月額視聴料（税込） | 3,960円（キャンペーン中は最大3ヶ月1,980円）::source{1}::source{2} | 4,054円::source{9} |
| チャンネル数 | 50::source{1} | 12::source{9} |
| スポーツのチャンネル | 4（J SPORTSは含まない）::source{1} | 7（J SPORTS 1〜3を含む）::source{9} |
| 基本料429円（税込） | 別途かかる::source{2}::source{3} | 別途かかる::source{3} |

**どちらを選ぶかの目安はシンプルです。** 見たい試合がJ SPORTSで放送されるなら、基本プランだけでは見られません。その場合は[スカパー！プロ野球セットの料金と加入前の確認点](/compare/skyperfectv-baseball-review/)を読んでください。見たい試合が上の4チャンネルで放送されるなら、**基本プランのほうがチャンネル数が多く、キャンペーンも使える**分だけ有利になります。

**ここで1つ、はっきり書いておくことがあります。** どの球団の主催試合がどのチャンネルで放送されるかの対応は、**今回スカパー！の公式ページで確認できませんでした。** 2026年のクライマックスシリーズ・日本シリーズをどのチャンネルが中継するかも同様です。「基本プランに入れば応援している球団の試合が必ず見られる」とは書けません。**申し込む前に、スカパー！の番組表で、見たい試合のチャンネルが基本プランの4チャンネルに入っているかを確かめてください。** 前述のとおり加入当月は解約できないので、この確認がいちばん大切です::source{4}。

## 録画と、家族での見方

基本プランは**録画もできます**::source{1}。ただし公式のキャンペーンページには、一部の番組は録画できないという注記があります::source{2}。毎回残したい番組がある場合は、番組ごとの扱いを確認しておくと安心です。

スカパー！の放送の契約は、テレビやレコーダーに入っているB-CASカード番号・ACAS番号ごとに結ぶ仕組みです::source{6}。本来はテレビとレコーダーで別々に契約が必要ですが、**基本プランは3台まで追加料金がかかりません**::source{5}::source{6}。条件は、各契約の契約者の氏名・住所・電話番号が同じであること、支払い情報が同じであること、各契約で同じ商品を契約していることの3つです::source{5}。リビングのテレビと録画用のレコーダー、子ども部屋のテレビ、といった組み合わせでも1台分の視聴料で済む計算になります。

## 申し込む前に確認する機器と、視聴開始までの時間

基本プランのスポーツ4チャンネルは、いずれもCS放送のチャンネルです::source{1}。公式FAQによると、**BS専用のアンテナではCS放送は受信できず、BSとCSの両方に対応したアンテナが必要**です::source{8}。自宅のアンテナがBSしか映らない場合は、アンテナの対応状況を先に確かめてください。

なお、光回線テレビやケーブルテレビの経路で見る場合は、アンテナが要らないこともあります。ただし光回線テレビと同時に申し込む場合は、スカパー！の加入手続きより先に、光回線の開通工事とテレビへの接続工事が必要になります::source{2}。**この記事では、BS・CS対応のアンテナとテレビがすでにある家庭が、公式サイトからWebで申し込む場合を前提にしています。**

公式FAQでは、手続きが終わったあとテレビで「受信待機」をすると、**30分ほどで視聴できる**と案内されています::source{7}。10月末の締め切り間際でも、試合当日に慌てずに済むよう、余裕を持って申し込むのがおすすめです。

## よくある質問

### キャンペーン中は、毎月いくら払いますか

加入した月は0円です::source{2}。翌月から最大3ヶ月間は、視聴料1,980円（税込）に基本料429円（税込）を足した**2,409円**です（記事側の足し算）::source{2}。その後は視聴料3,960円（税込）＋基本料429円（税込）＝**4,389円**になります（記事側の足し算）::source{1}::source{2}。

### 以前スカパー！に入っていました。キャンペーンは使えますか

キャンペーンは**初めてスカパー！に加入する人**が対象です::source{2}。以前解約したときと同じB-CASカード・ACAS番号で入り直す場合は対象外と明記されています::source{2}。

### 基本プランでプロ野球は見られますか

基本プランにはスカイA・GAORA SPORTS・日テレジータス・スポーツライブ＋の4チャンネルが入っています::source{1}。ただし**J SPORTS 1〜3は入っていません**::source{1}::source{9}。また、どの球団の試合がどのチャンネルで放送されるかは今回確認できなかったため、**申し込む前に番組表で、見たい試合のチャンネルを確かめてください。**

### 1ヶ月だけ使ってやめられますか

できません。**加入した月のうちは解約の手続きができず、翌月以降になります**::source{4}。解約した月の分まで料金がかかるので、キャンペーン中でも最低で加入翌月の2,409円がかかります（記事側の足し算）::source{2}::source{4}。

### いつまでに申し込めばキャンペーンの対象になりますか

2026年10月31日の申込み受付分までです::source{2}。加入と同じ月に基本プランを契約することも条件なので、**加入と基本プランの契約は同じ月のうちに済ませてください**::source{2}。
